- Fixed a session that stayed unable to send agent messages after another daemon held its mesh claim. The daemon now enrolls the session again on its next send, within the send's deadline, or on a roster change at most every 30 seconds, and logs the refusal only once while the claim stays held.
- Added the daemon that runs the session, and the `--daemon-socket` commands to run there, to `prime-agent stop` and `prime-agent move` errors when the daemon they reached cannot stop or move the session. A move refused for a held claim or an open file without a live host says what to close or stop.
- Added a warning to `prime-agent status` and `prime-agent doctor` when two running daemons use the same session folder. Each lists the other's saved sessions, so a stop or move sent to one can name a session the other runs and fail.
