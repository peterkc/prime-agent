- Fixed provider header values that extensions register at runtime being resolved as config values. A value starting with `!` ran a shell command, and any other value was first read as an environment variable name, so a header carrying session data from a crafted session file could run a command or send an environment variable to the provider. Extension header values are now sent as written. Headers in `models.json` still resolve environment variables and `!` commands. An extension that passed an environment variable name should read `process.env` itself.
